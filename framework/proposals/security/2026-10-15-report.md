# security — legislative report for 2026-10-15

## What I observed
During the legislative period of 2026-10-15 the following observations were made:
- Production administration tools (e.g., host reboot, configuration reload) are executable by any engineer with SSH access to production hosts, exceeding the principle of least privilege.
- CI/CD pipelines have broad read access to the entire secrets vault and the retrieved secrets are not time‑bound, allowing them to linger far beyond the job execution window.
- Service A’s outbound network policy is defined as an open allow‑list (0.0.0.0/0), exposing the service to arbitrary internet endpoints and increasing the attack surface.
- Database credentials are stored in plaintext within a version‑controlled repository, violating secret handling policies.
- Privileged SSH host keys are shared across multiple services, creating unnecessary blast‑radius if any key is compromised.

## Open risks
- Overbroad production admin tool access for all engineers
- CI pipelines can read all vault secrets and retain them indefinitely
- Unrestricted outbound network allow‑list for Service A
- Plaintext database credentials in source control
- Shared privileged SSH host keys across services
