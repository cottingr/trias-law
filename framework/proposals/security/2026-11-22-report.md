# security — legislative report for 2026-11-22

## What I observed
During the reporting period (2026-11-22) internal audits and access‑log probes revealed several privilege‑overreach patterns: CI pipelines in multiple projects possess read access to the entire secret vault regardless of the secrets they actually need; a monitoring service account is granted unrestricted host‑level SSH access while its functional requirement is limited to log collection; and a number of code repositories contain hard‑coded secret identifiers, exposing secret references to any contributor with repository access. These findings indicate violations of the least‑privilege principle and increase the estate’s attack surface.

## Open risks
- CI pipelines can read any secret, violating least‑privilege.
- Monitoring service account has unrestricted host SSH, increasing lateral movement risk.
- Hard‑coded secret identifiers in repositories may lead to secret leakage.
