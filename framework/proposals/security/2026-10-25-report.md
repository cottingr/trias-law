# security — legislative report for 2026-10-25

## What I observed
During the legislative session for period 2026-10-25 the following observations were made:
- Developer IAM roles were granted broad wildcard permissions (e.g., "*:*" on the entire project) that exceed the actions required for day‑to‑day development tasks.
- Multiple services were observed reading secrets from other services' namespaces, indicating cross‑service secret exposure.
- Compute instances have an egress allow‑list that permits traffic to any external IP (0.0.0.0/0), providing unnecessary internet exposure.
- CI pipelines receive long‑lived temporary credentials (24‑hour TTL) which remain valid far beyond the build execution window.
These patterns violate the principle of least privilege and expand the estate’s attack surface.

## Open risks
- Overbroad IAM role for developers
- Cross‑service secret exposure
- Unrestricted outbound network traffic from compute instances
- Long‑lived CI temporary credentials
