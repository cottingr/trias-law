# architecture — legislative report for 2026-11-22

## What I observed
During the period 2026‑11‑22 the following drifts were detected:
1. Service A performed direct database writes, bypassing the deterministic Gate token required for all state‑modifying actions.
2. Team X duplicated the ARC‑001 policy file into a legacy repository without synchronisation, creating a divergent copy of the law.
3. EventBus messages emitted by Service B and consumed by Service C were transmitted without any declared schema, risking type mismatches and runtime failures.
These incidents indicate violations of the architectural contract that all actions must flow through the Gate and that all cross‑component communications must be schema‑driven, as well as a breach of the single source of truth for policy documents.

## Open risks
- Unauthenticated state changes via direct DB access can bypass audit and violate deterministic control.
- Policy divergence may lead to inconsistent enforcement across services.
- Unvalidated inter‑service messages can cause runtime errors and data corruption.
