# architecture — legislative report for 2026-10-25

## What I observed
During the audit period 2026-10-25 the following drifts were recorded:

1. **Gate bypass** – Service `order-processor` invoked `inventory-service` via a direct HTTP call to an internal endpoint, omitting the required Gate token validation step.
2. **Missing schema registration** – Event `ShipmentCreated` was emitted without an entry in the central schema registry, causing downstream consumers to fall back to ad‑hoc schema inference and resulting in version mismatches.
3. **Policy copy divergence** – A copy of the architecture policy `ARC-001` was discovered in a feature branch of the `infra-config` repository that is not the authoritative source, creating a risk of divergent enforcement.
4. **Unaudited privileged action** – The `admin-dashboard` performed a direct database migration without routing through the deterministic action layer, bypassing the Gate and leaving no audit record.

These observations indicate multiple boundary violations, schema drifts, and audit gaps that threaten system determinism and separability.

## Open risks
- Unauthorized inter‑service actions without a validated Gate token can lead to privilege escalation and data leakage.
- Unregistered or out‑of‑sync message schemas increase runtime failures and reduce contract clarity between components.
- Duplicated policy copies risk divergent enforcement, undermining the single source of truth for architectural constraints.
- Direct privileged operations outside the deterministic layer erase audit trails, weakening accountability and incident response.
