# architecture — legislative report for 2026-11-01

## What I observed
During the current period, the engineering team observed several instances where services have begun to call the user‑profile database directly via shared library imports, completely bypassing the deterministic Gate layer. Additionally, a number of event‑bus messages were emitted without corresponding entries in the central schema registry, leading to undocumented payload structures drifting between services. Finally, a copy of the original ARC‑000 founding template was modified in a feature branch without being merged through the official Ledger, creating an out‑of‑sync version of the policy that could be mistakenly referenced.

## Open risks
- Unauthorized direct calls to critical services can elevate privileges without Gate verification.
- Undocumented message schemas cause data contract violations and runtime errors.
- Untracked policy copies undermine the integrity of the Ledger and may be used as authoritative references.
